# Qualitative transcript analysis: working template

> Use this template with de-identified transcripts. Do not place identifiable participant data in a public repository. The two-to-five-word code and theme labels and five-to-six-theme target are user-requested defaults, not universal methodological rules.

## 1. Analysis frame
- Study/topic:
- Research question:
- Analytic approach:
- Transcript(s) covered:
- Dataset limitations:
- Ethics/confidentiality instructions:

## 2. Transcript summary
Write a concise summary that directly addresses the research question. Separate participant account from analyst interpretation. Preserve context, qualifications, contradictions and unexpected points.

## 3. Initial coding and evidence register
| Research question | Transcript ID | Exact transcript excerpt | Initial code (2–5 words) | Analytic note |
|---|---|---|---|---|
| | | | | |

## 4. Code-to-theme development
| Candidate theme (2–5 words) | Related codes | Central organising concept | Supporting transcript IDs | Divergent evidence | Decision |
|---|---|---|---|---|---|
| | | | | | Retain / revise / merge / split / discard |

## 5. Final thematic table: three-column format
| Theme (2–5 words) | Summary of the finding | Supporting transcript excerpts |
|---|---|---|
| | | |

Keep quotations verbatim and attribute them to the correct participant. Add page, line or timestamp references only when supplied or verified. Do not invent quotations to fill gaps.

## 6. Cross-theme synthesis
Explain how the themes collectively answer the research question. Identify relationships, tensions, exceptions and gaps. Do not treat frequency as the only measure of significance.

## 7. Quality and traceability check
- [ ] Research question is explicit.
- [ ] Transcript coverage is stated accurately.
- [ ] Summaries are grounded in supplied data.
- [ ] Codes are concise and evidence-linked.
- [ ] Themes have distinct central organising concepts.
- [ ] Theme labels meet the requested word range where feasible.
- [ ] Requested three-column table is preserved.
- [ ] All excerpts are authentic and traceable.
- [ ] Divergent accounts are represented.
- [ ] No unsupported prevalence, causal or generalisability claims are made.
- [ ] Confidentiality requirements are met.
